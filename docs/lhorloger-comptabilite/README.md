# Dossier de développement — Comptabilité L’Horloger

Ce dossier prépare l’implémentation du futur espace Comptabilité dans l’administration L’Horloger. Il est inspiré des principes de trésorerie de KAMNI, mais reprend le fonctionnement réel de L’Horloger : paiement à la réception, closeuse séparée, panier multi-montres regroupé par `order_ref`, stock simple et coûts Meta déjà saisis.
